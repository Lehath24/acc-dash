# ACC телеметрия

Приборная панель для **Assetto Corsa Competizione** на ПК и Android-планшете: скорость,
педали, шины и тормоза, топливо и совет на пит-стоп, секторы, карта трассы, соперники.

Здесь лежат только готовые сборки. Скачать — раздел [Releases](../../releases/latest).

## Что скачать

| Файл | Куда |
|---|---|
| `acc_dash.exe` | ПК, где запущена ACC. Устанавливать ничего не нужно |
| `acc_dash_tablet.apk` | Android-планшет (по желанию) |

## Как пользоваться

1. Запустите `acc_dash.exe`. Windows может предупредить, что программа не подписана:
   «Подробнее» → «Выполнить в любом случае». Доступ к сети — «Разрешить» (частные сети).
2. Установите `acc_dash_tablet.apk` на планшет. Планшет и ПК — в одной сети Wi-Fi.
   Приложение само найдёт ПК и покажет панель.

## Обновления

В окне на ПК есть кнопка **«ОБНОВЛЕНИЯ»**: она скачивает новую версию отсюда и
перезапускает программу. Интерфейс планшета приходит вместе с ПК-программой, поэтому
планшет обновлять не нужно.
